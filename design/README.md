# Дизайн

Интерфейс «Финни» сделан кодом: цвета, шрифты и размеры — в теме
приложения [`mobile/lib/theme/kids_theme.dart`](../mobile/lib/theme/kids_theme.dart),
эффекты и дороги заданий нарисованы через `CustomPainter`.

В этой папке — только файлы для публикации, которые не собираются в APK:

```text
design/
└── icon/
    └── icon-512.png   иконка приложения 512×512 для карточки RuStore
```

Иконка на самом телефоне — адаптивная, лежит в
`mobile/android/app/src/main/res/mipmap-*`.

Требования доступности, которые соблюдает интерфейс: текст от 16sp,
касаемые элементы от 48×48dp, состояние передаётся не только цветом
(текст, эмодзи, иконки), портретная ориентация от 360dp.
